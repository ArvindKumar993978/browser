Split View + Smart Pane Focus

View two live tabs side-by-side (Ctrl+\) or switch to Vertical Tabs anytime. Click either pane to target it from the address bar.

8 GB RAM Tab Sleeping + Shield

Inactive silent tabs automatically sleep to free memory, while Ghostery filters ads and trackers locally with zero Orbit telemetry.

Everything You Need in a Real Daily Browser

Engineered with strict process isolation, built-in SQLite persistence, and zero bloat.

Workspaces & Vertical Tabs

Separate Personal, Work, and Research tabs cleanly. Drag to reorder tabs in top bar or vertical sidebar mode.

Side-by-Side Split View

Open any two tabs side-by-side with Ctrl+\, swap panes with one click, or right-click any link to open in Split View.

Ad & Tracker Shield

Powered by Ghostery's filter engine cached locally, with a live per-tab blocked counter and one-click per-site allowlist.

Zero-XSS Reader Mode

Press Ctrl+Alt+R for distraction-free reading with Dark, Sepia, and Light themes—rendered safely from plain-text blocks.

8 GB RAM Tab Sleeping

Automatically suspends idle background tabs (without interrupting playing audio) and wakes them seamlessly on click.

Command Palette & Private Mode

Jump across tabs and commands with Ctrl+K, or open isolated in-memory Private Windows with Ctrl+Shift+N.

Verify & Install on Windows

Orbit Browser uses an NSIS Windows installer with automatic updates via GitHub Releases. Because v0.1.2 is an indie beta build without a paid EV code-signing certificate yet, Windows SmartScreen may show "Windows protected your PC"—click More info → Run anyway.
